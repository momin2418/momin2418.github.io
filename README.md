# Mominul Islam Momin — Portfolio Website

A responsive, dark-modern personal portfolio built with plain HTML, CSS, and JavaScript. No build tools or paid hosting required.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, responsive styles
- `script.js` — mobile navigation, current year, copy-profile button
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing

## Publish with GitHub Pages (free)
1. Sign in to GitHub as `momin2418`.
2. Create a **public** repository named exactly `momin2418.github.io`.
3. Upload all files from this folder to the repository root (not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes, then visit `https://momin2418.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart
